An original open-world crime game in the spirit of GTA 6, playable offline in a desktop browser from static files. A city on foot and by car, traffic and pedestrians, cars to steal, a wanted level and police, missions and a story, combat, a HUD with a minimap, a start and a save.

Built fresh in a recorded agent session for make.fun bounty gta6-01. All city, characters, vehicles, names, story, art, sound and music are original — nothing from Rockstar Games.

## Play

Serve `game/` (for example `node serve.ts`) and open it in desktop Chrome.
